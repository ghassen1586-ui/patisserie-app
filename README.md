# Patisserie App 🥐

An e-commerce web application for a patisserie store built with Angular 21.

## Features
- Product catalog with dynamic display
- Shopping cart with service-based state management
- Reactive forms with validation (login, delivery, payment)
- Authentication guard protecting routes
- Admin dashboard with user management
- Dark/light mode support
- Responsive design with TailwindCSS

## Tech Stack
- Angular 21 (standalone components)
- TypeScript
- Reactive Forms
- RxJS / HttpClient
- JWT Auth (service layer)
- TailwindCSS

## Run locally
```bash
npm install
ng serve
```
